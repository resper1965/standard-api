# Glossário

## Aegis

Produto para assessments de segurança, conformidade e maturidade baseados no Secure Controls Framework.

## SCF

Secure Controls Framework. Fonte normativa estruturada usada pelo Aegis.

## Assessment

Execução de avaliação para uma organização/tenant, com documentos, escopo, SoA, Gap Analysis, Maturity, POA&M e relatório.

## SoA

Statement of Applicability. Artifact que define aplicabilidade e escopo de controles/requisitos.

## Gap Analysis

Artifact que registra gaps, evidências, ausência de evidência e necessidade de validação.

## POA&M

Plan of Action & Milestones. Plano de ações vinculado a gaps, controles e requisitos.

## KB

Knowledge Base de evidências do cliente. Não é fonte normativa.

## Agent Runtime

Camada de execução controlada de agentes funcionais, com tools, guardrails, schema validation e auditabilidade.

## Approval Gate

Ponto obrigatório de aprovação humana para artifacts críticos.

## Placeholder

Informação ainda não fechada. Deve ser substituída por decisão documentada quando houver definição.
