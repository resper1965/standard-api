# SCF Core

Fonte normativa estruturada do Secure Controls Framework para o Aegis.

Nesta fase inicial não há dados reais do SCF. Quando o catálogo for integrado, mapeamentos oficiais devem vir de dados estruturados versionados, não de busca vetorial.

Responsabilidades futuras:

- versionar releases do SCF;
- expor controles, domínios, objetivos e mapeamentos por framework;
- validar `framework_id`, `control_id` e `scf_version`;
- impedir que respostas LLM alterem mapeamentos oficiais sem revisão humana.
